# X Bikes Showroom — رندر ثلاثي الأبعاد تفاعلي لمعرض هوندا

> 🇰🇼 جولة ثلاثية الأبعاد في المعرض الجديد، نتمشى فيها شرات لعبة فيديو، داخل وبرّا. تفتح من التلفون واللابتوب بلينك واحد، والهدف ناخذ موافقة الإدارة على التصميم.

## الطوابق
| الطابق | شنو فيه |
|---|---|
| الجراوند فلور | منطقة عرض السيارات + المدخل والباب الزجاجي |
| اللور جراوند | ثلاث زونات: Honda Bikes و Honda Marine و Honda Power Products |
| الميزانين | مكاتب الموظفين والإدارة |

## التشغيل على الجهاز
1. دبل كليك على `run-local.cmd`.
2. يفتح المتصفح على http://localhost:5173 (لو ما فتح، افتحه بنفسك).
3. لإيقاف السيرفر سكّر نافذة PowerShell.

> فتح `index.html` مباشرة من الفولدر ما يشتغل، لازم السيرفر.

## التحكم
| | الديسكتوب | الموبايل |
|---|---|---|
| المشي | `W A S D` أو الأسهم | الجويستيك تحت يسار |
| اللف والنظر | الماوس (اضغط على المشهد أول) | اسحب بإصبعك على الشاشة |
| الركض | `Shift` | — |
| الطوابق | الأزرار فوق أو `1` `2` `3` `4` | الأزرار فوق |
| إظهار الماوس | `Esc` | — |

## ترتيب الفولدر
| الفولدر / الملف | شنو فيه |
|---|---|
| `index.html` | الصفحة الرئيسية |
| `src/config.js` | **ملف الإعدادات:** كل المقاسات والألوان والأماكن والمنتجات. أي تعديل يبدأ من هني |
| `src/` | باقي الكود (المبنى، المنتجات، التحكم، الواجهة) |
| `assets/models/` | موديلات المنتجات GLB |
| `assets/ci/` | اللوقو والخطوط الرسمية (من الـ CI فقط) |
| `references/` | المواد اللي نبني عليها: الفلور بلان، الفيديو والفريمات، الموكابس، الـ CI، الريفرنسز |
| `docs/PLAN.md` | الخطة وحالة كل خطوة والأسئلة المفتوحة |
| `tools/serve.ps1` | سيرفر محلي صغير للتجربة |

## الحالة الحالية
النسخة الأولى شغالة: فيها المشي والطوابق الثلاثة والدرج والباب الأوتوماتيك وأزرار الإظهار/الإخفاء.
**كل المقاسات مؤقتة** إلى ما يوصل الفلور بلان، والمنتجات أشكال مبدئية إلى ما توصل الموديلات. التفاصيل في `docs/PLAN.md`.
